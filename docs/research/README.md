# Research notes

Memos that answer a question the [research priorities](../roadmap/research-validation-priorities.md)
ask before work starts: what a model, a dataset or a comparison offers,
checked against its sources, and what it would take. A memo recommends; a
decision record decides. A memo is dated by when its sources were checked,
and is not rewritten as they change: a later check is a new memo.
