# Roadmap archive

The documents of finished projects, with their clean-ups and QA reports once
their plans are done or carried elsewhere
([decision 0070](../../decisions/0070-a-finished-project-moves-to-the-roadmaps-archive.md)).
Each is as it stood when its project closed. The [roadmap](../README.md)'s
table still lists each project, linking here, so its step identifiers are
found from there.

Read a document here only when a task cites its steps or asks for its
history: what is open is in the [roadmap](../README.md) outside this folder.
